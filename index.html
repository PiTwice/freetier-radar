FAQ

How is the data verified?
Every entry is checked by a human against the provider's official pricing page or docs, and stamped with the verification date you see on each card. A monitoring script watches pricing pages for changes and flags entries for re-review.
What counts as a "trap"?
Anything a pricing page technically discloses but you'd realistically miss: databases that pause or expire, hard caps that take your site down, "no commercial use" clauses, trial credits disguised as free plans, and data deletion policies.
A limit changed / something is wrong. How do I report it?
Open an issue or a pull request on GitHub — the data lives in a single tools.json file, so a fix is a one-line change. Corrections are usually merged within a day.
Do providers pay to be listed here?
No. No sponsorships, no affiliate links, no "featured" placements. That's the whole point — the moment rankings are for sale, a directory like this is worthless.
